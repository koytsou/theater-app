# Theater App

A cinematic mobile application for theatre ticket reservations, built with Expo, React Native, Firebase Authentication, and Cloud Firestore.

## Features

- User registration and login
- Firebase Authentication with persistent session
- Browse available theatre shows
- View show details
- Select seats from an interactive seat map
- Create and update reservations
- Cancel active reservations
- View user reservations
- Firebase Firestore backend
- Firestore Security Rules for authorization

## Technology Stack

- Expo SDK 54
- React Native 0.81
- React 19
- Firebase Authentication
- Cloud Firestore
- React Navigation Native Stack
- AsyncStorage
- Expo Vector Icons
